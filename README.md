# Ransom

Ransom from DOORS: The Archives, in Geometry Dash.

Each attempt has a 1/N chance (setting) for Ransom to flash on screen for 0.5s.
Jump while it's visible and your pause menu gets encrypted: every button is locked
with a custom icon until you collect the coins. Run out of time and you die.

Custom button icons: `resources/ransom-<node-id>.png` (e.g. `ransom-play-button.png`).
`ransom-button.png` is the fallback for any button without its own icon.
